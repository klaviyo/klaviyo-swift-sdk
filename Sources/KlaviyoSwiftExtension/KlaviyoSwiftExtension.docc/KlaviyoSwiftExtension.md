# ``KlaviyoSwiftExtension``

Add rich media, badge counts and action buttons to Klaviyo push notifications.

## Overview

`KlaviyoSwiftExtension` runs inside your app's Notification Service Extension. Forward the
extension's callbacks to ``KlaviyoExtensionSDK`` to download rich media attachments, update
the badge count and register push action buttons.
