# ``KlaviyoSwift``

Identify profiles, track events, and handle push notifications with Klaviyo.

## Overview

`KlaviyoSwift` is the core product of the Klaviyo Swift SDK. Initialize it with your public
API key, then use ``KlaviyoSDK`` to identify the current profile, record events, and register
for push notifications.
