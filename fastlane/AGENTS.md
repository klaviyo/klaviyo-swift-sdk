# fastlane

Legacy release lanes (`Fastfile`): `fastlane ios patch|minor|major` (run with `bundle exec`, using the root
`Gemfile`). Each lane lints and bumps **only** `KlaviyoSwift.podspec`, commits, tags, pushes and runs
`pod push`.

Current releases go through `.github/workflows/publish-release.yml` and
`cocoapods-publish.yml`, which handle every podspec. Version bumps go through `../bump-version.sh`. Do not
use these lanes for a normal release without checking with the maintainers.

- `README.md` is auto-generated by fastlane. Don't edit it by hand.
- `report.xml` is a fastlane run artifact.
- `Appfile` holds only commented-out placeholders.
