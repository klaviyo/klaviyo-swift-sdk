# Staged shared-CI changes for `.github/`

This directory holds the intended end state of every new or changed file under `.github/` for MAGE-1728 (part of MAGE-1725), because the branch's push token can't write workflow files. `ci-staging/github/<path>` is the full content of `.github/<path>`, and `ci-staging/DELETE` lists the `.github/` files to remove. Applied, the repo stops carrying its own copy of `notify-slack` and calls the shared CI in klaviyo-react-native-sdk instead: `publish-release.yml` runs `release-preflight.yml` for its prepare job, `rel-branch.yml` runs `rel-branch-core.yml`, `pr-target-check.yml` and `stale.yml` become stubs over the shared actions, a new `promotion-check.yml` lists this repo's `bump-files`, `spm-verify.yml` uses `linear-release-sync`, and every Slack step uses the remote `notify-slack`. All refs point at `@ecm/mage-1726/shared-ci` until that branch merges, then flip to `@master`. To apply: copy `ci-staging/github/*` over `.github/`, `git rm` each path in `DELETE`, then delete `ci-staging/`.
